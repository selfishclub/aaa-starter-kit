# 파일명 규칙

## 미션 파일 (00_missions/)

- 위치: `00_missions/Week_0N_submit/Week_0N_{닉네임}_submit.md`
- 예: `00_missions/Week_02_submit/Week_02_홍길동_submit.md`
- 주차별 폴더는 운영자가 미리 만들어둠

## 갤러리 파일 (01_gallery/)

- 파일명 자유 (예: `my-project.md`, `AI-chatbot.md`)
- frontmatter에 `maker`, `link`, `thumbnail` 필수

## 스킬·인사이트 파일 (02_skill_insight/)

- 파일명 자유 (예: `claude-code-tips.md`, `figma-plugin.md`)
- frontmatter 없이 순수 마크다운도 허용 (`/publish` 시 자동 태깅됨)

## 회의록 (01_meetings/)

- 위치: `01_meetings/Week_0N_weekly.md`
- 비공개 폴더 (홈페이지에 노출 안 됨)

## 공통 규칙

- 띄어쓰기 대신 언더스코어(`_`) 또는 하이픈(`-`) 사용
- 특수문자(`?`, `%`, `(`, `)`) 금지 — Astro 빌드 깨짐
- 확장자는 `.md`
- 한글 파일명 허용
