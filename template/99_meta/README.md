# 99_meta — 운영 메타데이터

이 폴더에는 팀 운영에 필요한 **구조적 정보**가 들어갑니다. 홈페이지에는 공개되지 않습니다.

## 구성

| 파일 | 용도 |
|------|------|
| `멤버목록.md` | 활성 멤버 리스트 (슬래시 명령어가 참조) |
| `파일명규칙.md` | 파일명 컨벤션 |
| `명령어가이드.md` (선택) | 팀 내부 슬래시 명령어 사용법 |
| `시스템가이드.md` (선택) | 신규 멤버 온보딩 가이드 |

## 추가 권장 파일 (팀 성격에 맞게)

- `회비및벌금.md` — 회비 체계를 쓰는 팀
