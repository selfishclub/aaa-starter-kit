# 00_missions — 주차별 과제

## 구조

```
00_missions/
├── Week_01_submit/
│   ├── Week_01_홍길동_submit.md
│   └── Week_01_김철수_submit.md
├── Week_02_submit/
│   └── ...
```

## 운영자 준비

매 주차 시작 전 운영자가 다음을 해둡니다.

1. `Week_0N_submit/` 폴더 생성
2. 활성 멤버마다 `Week_0N_{닉네임}_submit.md` 빈 파일 생성
3. `99_templates/미션_Week_0N_닉네임_submit.md` 내용으로 프리필

## 멤버 제출

- 본인 파일만 수정
- 저장하면 obsidian-git이 자동 push

## 공개 범위

홈페이지 `/archive/` 또는 `/missions/`에 **공개**됩니다.
