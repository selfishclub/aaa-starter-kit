# 90_analysis — AI 자동 생성 분석

이 폴더의 내용은 대부분 `/analyze N` 실행 시 **자동 생성**됩니다. 직접 편집하기보다는 슬래시 명령어로 갱신하세요.

## 구조

```
90_analysis/
├── weekly/                      ← AI 주간 분석 리포트 (공개)
│   ├── Week_01_분석.md
│   └── Week_02_분석.md
└── members/                     ← 멤버 프로필 (공개)
    ├── 홍길동_프로필.md
    └── 김철수_프로필.md
```

## 공개 범위

- `weekly/` → 홈페이지 `/analysis/`
- `members/` → 홈페이지 `/team/`

## 초기화

첫 주차 시작 전에는 둘 다 비어있어도 됩니다. `/analyze 1` 실행 시 첫 파일이 생성됩니다.
