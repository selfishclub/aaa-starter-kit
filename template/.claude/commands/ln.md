$ARGUMENTS 주차 멤버들의 과제를 바탕으로 링크드인 포스트를 생성해줘.

## 실행 절차

### 1. 데이터 수집
- `00_missions/Week_0$ARGUMENTS_submit/` 의 제출된 멤버 파일(`Week_0N_닉네임_submit.md`) 읽기 (10바이트 이하 건너뛰기)
- 각 멤버의 결과물, 만든 과정, 인사이트 섹션 파악
- 배포된 링크, 구체적 숫자, 기술 스택 추출

### 2. 멤버별 링크드인 포스트 생성

각 제출 멤버마다 `_linkedin/Week_0$ARGUMENTS_닉네임.md` 파일을 생성한다.

### 링크드인 알고리즘 최적화 규칙

- **글자 수**: 1,200~1,500자 (한국어 기준, 최대 3,000자)
- **첫 2줄이 핵심**: "...더보기" 전에 보이는 부분. 반드시 스크롤을 멈추게 하는 후킹
- **줄바꿈**: 한 문장씩 끊고 빈 줄로 구분 (가독성 = 알고리즘 보상)
- **링크 금지**: 본문에 외부 링크 넣으면 도달률 하락. 링크는 첫 번째 댓글에
- **이모지**: 최대 3개, 장식이 아닌 시각적 앵커로만 사용
- **해시태그**: 본문 끝에 3~5개 (넓은 태그 + 니치 태그 혼합)
- **CTA**: 마지막에 질문이나 의견 요청으로 댓글 유도

### 포스트 구조

```
---
member: 닉네임
week: N
tags:
  - 링크드인
status: draft
---

[후킹 — 반전, 놀라운 숫자, 또는 개인 경험으로 시작. 2줄 이내]

[컨텍스트 — 왜 이걸 했는지, 어떤 문제를 풀려 했는지]

[인사이트 — 핵심 배움 3가지를 번호로 정리]

1️⃣ (결과물) 뭘 만들었는지
2️⃣ (과정) 어떻게 만들었는지, 어떤 삽질을 했는지
3️⃣ (배움) 이걸 통해 뭘 깨달았는지

[테이크어웨이 — 한 줄 핵심 요약]

[CTA — 질문으로 끝내기]

#selfish_AAA_Team #AI #ClaudeCode #빌더 #스터디
+ 주제별 해시태그 1~2개 추가

---
**첫 번째 댓글에 넣을 링크**: [배포 URL이 있으면 여기에]
**멤버 태그 안내**: 링크드인에서 직접 @를 눌러 아래 멤버를 태그하세요
(복붙으로는 태그가 되지 않습니다. 앱에서 직접 @입력 필요)
**글자 수**: X/3,000
```

### 후킹 첫 줄 작성법

**좋은 예시:**
- "Claude Code 하나로 하루 만에 웹사이트를 배포했습니다."
- "URL 하나 넣었더니 8개 채널 콘텐츠가 자동으로 나왔습니다."
- "AI에게 답을 구하지 않고, 질문을 던지게 만들었습니다."
- "5년간 100개 스타트업을 분석한 결과, 성공한 팀에는 하나의 공통점이 있었습니다."

**나쁜 예시:**
- "오늘은 리더십에 대해 이야기하려고 합니다." (너무 뻔함, 더보기 누를 이유 없음)
- "이번 주 스터디 과제를 했습니다." (후킹이 아님)

### 톤 & 스타일
- **합니다체** (한국어 기본) — 문장은 짧고 펀치있게
- **1인칭** — "저는", "제가" 사용, 진정성 있는 개인 경험
- 기업 용어 금지 ("시너지", "레버리지", "패러다임" 등)
- 똑똑한 동료에게 말하듯 — 이사회 발표가 아니라 커피챗 느낌
- 구체적 숫자와 결과물 필수 ("8채널", "하루 만에", "5장 카드뉴스")
- 멤버의 과제 내용만 기반으로 작성 (추측하지 않기)

### 3. 결과 안내
생성된 초안 파일 목록을 보여주고:
- "첫 번째 댓글에 넣을 링크"가 있으면 함께 안내
- 멤버가 본인 스타일로 수정 후 게시하도록 안내
- 게시 후 `92_status/진행현황.md` 링크드인 포스팅 테이블에 링크 추가 요청
