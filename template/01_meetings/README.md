# 01_meetings — 주간 회의록 (비공개)

매주 정기 회의 내용을 기록합니다. **홈페이지에 공개되지 않습니다.**

## 파일 형식

- 파일명: `Week_0N_weekly.md`
- 템플릿: `99_templates/회의록_Week_0N.md`

## 왜 비공개인가

회의록에는 다음 같은 민감한 내용이 있습니다.
- 멤버 개인 상황·감정
- 운영 의사결정 과정
- 벌금·MVP 투표 상세
- 외부 공유 부적절한 초기 아이디어

`/analyze N` 명령어가 이 회의록을 **읽어서** 핵심 인사이트만 추출해 공개 분석 리포트로 가공합니다. 원본은 절대 공개되지 않습니다.
