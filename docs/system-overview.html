03

AI가 대신 하는 네 가지

슬래시 명령어
/analyze N
주간 분석 자동 생성
N주차 멤버 과제 + 회의록을 통째로 읽고 트렌드·키워드·독특한 시각을 리포트로 뽑아낸다.
/ln N
링크드인 초안
그 주차 과제를 기반으로 링크드인 포스트 초안을 자동 생성한다.
/archive
아카이브 북 갱신
전체 기록을 훑어서 아카이브 북(전자책 형태)을 다시 빌드한다.
/publish
홈페이지 배포
공개 폴더만 골라 Astro 레포에 복사 → 빌드 → Vercel로 자동 배포까지.
